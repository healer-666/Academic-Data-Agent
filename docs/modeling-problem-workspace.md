# 数学建模赛题资料工作区

数学建模任务在开始制定分析方案前，先建立一份可审核的赛题资料包。普通用户只需在“分析任务”页面选择“数学建模项目”，一次提交：

- 一份赛题说明（TXT、Markdown 或可提取文本的 PDF）；
- 一份或多份 CSV、XLS、XLSX 数据；
- 可选的说明文档、图片或补充表格附件。

系统不会在上传后立即执行分析，而是先展示资料识别结果。

## 自动识别内容

- Excel 工作簿中的每个 Sheet 会作为独立数据表展示；
- 每张表展示来源文件、行列数、字段类型、唯一值、缺失值和样例值；
- 质量摘要包含缺失单元格、重复行、全空字段和常量字段；
- 系统根据字段名、取值重合度和唯一性推断一对一、一对多、多对一或多对多关系；
- 低置信度关系明确标记为“不确定”，不会当作已确认事实。

## 人工修正

用户可以在资料包审核区：

- 选择后续规划时优先关注的主表；
- 修改数据表的显示名称；
- 修改、添加或删除表间关系；
- 调整关系两端的表、字段、关系类型和审核状态；
- 记录字段含义和关系依据；
- 确认并保存资料包。

确认后的 `package.json` 保存在 `outputs/modeling_packages/<package-id>/`，原始上传文件保存在同一资料包的私有 `uploads/` 目录。对外响应不会暴露本地绝对路径。

## 与后续流程的关系

Issue #14 只负责可靠形成并确认赛题资料包。后续流程分别负责：

- Issue #15：根据资料包、历史案例和建模 skills 生成可调整的分析方案；
- Issue #16：在当前赛题数据上执行经过确认的方案并展示结果。

因此，多表资料不会被静默合并，也不会只取第一张表假装完成多表分析。
