# 2022 年 C 题与 C155、C229 论文解析

## 解析范围与结论

本案例解析对象为 2022 年全国大学生数学建模竞赛 C 题《古代玻璃制品的成分分析与鉴别》、题目附件，以及用户指定的 C155、C229 两篇展示论文。两篇论文的国一身份按用户确认记录，本次不再单独核验奖项名单。原题、附件、论文页面和 OCR 全文均只保存在维护者本地；仓库只保存本解析和后续通过审核的结构化案例卡片。

两篇论文的共同主线很明确：先把十四种化学成分当作“总和受约束的成分数据”处理，再依次完成风化关联、风化前成分预测、玻璃分类、未知样品鉴别和成分关联分析。二者对未知样品的大类结论完全一致，但在零值处理、风化前预测、分类阈值、亚类聚类和关联分析上采用了不同路线，适合作为同题多解案例。

## 题目与数据

题目要求完成四项任务：

1. 分析表面风化与玻璃类型、纹饰、颜色的关系；分类型描述风化前后成分规律，并预测风化前成分。
2. 建立高钾玻璃与铅钡玻璃的分类规律，进一步划分亚类，并分析合理性和敏感性。
3. 鉴别表单 3 中 8 件未知文物的玻璃类型，并分析结果敏感性。
4. 分类型分析十四种化学成分之间的关联，并比较两类关联结构的差异。

附件核对结果：

- 表单 1：58 件文物，其中铅钡 40 件、高钾 18 件；风化 34 件、未风化 24 件；颜色缺失 4 件。
- 类型与风化交叉分布：铅钡为 28 件风化、12 件未风化；高钾为 6 件风化、12 件未风化。
- 表单 2：69 条已知成分检测记录，全部能关联回表单 1；11 件文物含两个检测点。
- 按题目 85%—105% 的有效范围，编号 15 的成分和为 79.47%，编号 17 为 71.89%，应剔除；剩余 67 条有效。
- 表单 3：8 件未知文物，成分和均处于有效范围。
- 空白表示“未检测到”，不是普通随机缺失。已知记录中 Na2O、SnO2、SO2 分别有 50、62、61 个空白，零值/近零值处理会明显影响对数比变换。

## 两篇论文的方法对比

| 环节 | C155 | C229 | 解析判断 |
| --- | --- | --- | --- |
| 数据清洗 | 剔除 15、17；颜色缺失不填；未检测成分补 0 | 剔除 15、17；众数和热卡补颜色；空白及 0 用乘法替换 | C229 的近零替换更适合后续 clr；C155 的“补 0 后 clr”在数学上缺少必要说明 |
| 成分约束 | 闭合到 100%，clr 变换 | 乘法替换后闭合到 100%，在 Aitchison 单形几何下求均值并做 clr | 都抓住了成分数据的定和性质 |
| 风化关联 | 类型用 Pearson 卡方；稀疏的纹饰、颜色列联表用 Yates 校正 | Spearman 与卡方双路线 | 两篇均判定风化与类型有关，与纹饰、颜色无显著关系 |
| 风化前预测 | 聚类构造变化次序，在 clr 空间拟合成分趋势回归并逆变换 | Dirichlet 回归直接预测比例向量 | C229 的概率模型更贴合比例响应；两者都需验证外推稳定性 |
| 大类分类 | 按风化状态建两棵 PbO 决策树：未风化阈值 8.495%，风化阈值 6.155% | 统一 PbO 阈值 1.5%，再用 PLS-DA 复核 | 阈值差异很大，说明不可把单一历史阈值硬编码为通用规则 |
| 亚类划分 | R 型变量聚类选代表成分，再做 Q 型层次聚类 | 两类分别做 k-means，均取 3 类，再用 PLS-DA/VIP 选特征 | 都缺少亚类真值，聚类稳定性比“分成三类”本身更重要 |
| 未知样品 | 决策树预测，Q 型聚类交叉检查 | 决策树与 PLS 预测，亚类再用 PLS | 大类结果完全一致 |
| 成分关联 | 灰色关联分析，比较关联系数集中/离散 | Pearson 热力图，配对 Wilcoxon 比较两类相关矩阵 | 衡量对象不同，结论不能直接互证 |
| 验证 | 70%/30% 留出，四项分类指标均为 1；代表特征随机扰动约 10%—20% | 47/20 留出准确率 100%；PLS 以 CV-RMSEP 选主成分；双模型一致 | 满分指标需警惕小样本、同文物多检测点造成的信息泄漏 |

## 分问题结果

### 问题一：风化关系与风化前预测

C155 报告表面风化与玻璃类型的 Pearson 卡方检验 p=0.009；纹饰和颜色经校正后分别为 p=0.084、p=0.507。C229 的卡方结果分别为类型 0.024、纹饰 0.085、颜色 0.325，并用 Spearman 得到同方向结论。因此较稳健的共同结论是：在这 58 件样本中，风化状态与玻璃类型有关，但没有足够证据说明它与纹饰或颜色有关。

成分描述方面，两篇都按“类型 × 风化”形成四组。C155 使用均值、极值、标准差、变异系数、偏度、峰度和箱线图；C229 在单形几何下计算成分均值，并用内外环图比较风化前后占比。后者尤其强调：直接对百分比逐列做普通算术平均可能忽视成分总和约束。

风化前预测是两篇差异最大的部分之一。C155 先把同类样本聚成具有变化次序的组，再在 clr 空间拟合趋势；C229 使用 Dirichlet 回归。经验库中应把两者保存为两个候选策略，并要求新任务用留出或重采样评估后再选，而不是把任一论文的预测值当作事实。

### 问题二：大类与亚类

C155 分风化状态训练决策树：

- 未风化：PbO ≤ 8.495% 判高钾，PbO > 8.495% 判铅钡。
- 风化：PbO ≤ 6.155% 判高钾，PbO > 6.155% 判铅钡。

C229 给出统一规则：PbO > 1.5 判铅钡，否则判高钾；PLS-DA 选出的重要大类特征为 PbO、K2O、BaO、SrO。两个方案在本题样本上都报告很高精度，但阈值相差数倍，说明决策树只是对各自预处理结果的压缩表达，不能脱离数据处理口径复用。

C155 的亚类路线是“R 型聚类变量 → 选择代表成分 → Q 型聚类样本”，并对代表成分做随机扰动；不改变划分的扰动范围主要为 0.1—0.2。C229 对高钾、铅钡分别做 k-means，均选择 3 类：

- 高钾亚类特征：K2O、SiO2、CaO、SnO2、BaO。
- 铅钡亚类特征：P2O5、CuO、Na2O、Fe2O3。

### 问题三：8 件未知文物

两篇论文得到完全一致的大类结论：

- 高钾玻璃：A1、A6、A7。
- 铅钡玻璃：A2、A3、A4、A5、A8。

C229 进一步给出亚类关系：A1/A6/A7 属同一高钾亚类；A2/A4 属同一铅钡亚类；A3/A8 属另一铅钡亚类；A5 属第三个铅钡亚类。其大类 PLS 模型经交叉验证选择 3 个主成分，累计贡献率 93%；亚类 PLS 选择 2 个主成分。

大类一致是本题最强的跨论文共识，但仍不等于外部真值验证。更稳妥的复用方式是保留模型概率、离阈值距离和多方案一致性，而不是只存一个硬标签。

### 问题四：成分关联

C155 对每个成分轮流设为母序列，计算其余十三种成分的灰色关联度，观察到高钾玻璃的关联系数多集中在 0.9—1，铅钡玻璃更分散。C229 则分别计算 Pearson 相关热力图，再把两个相关矩阵的上三角元素配对进行 Wilcoxon 检验，得到 p=0.905，认为两类整体相关结构无显著差异。

这两个结论不能简单写成“论文互相矛盾”：灰色关联度与 Pearson 相关衡量的并非同一对象，前者比较形态接近程度，后者比较线性共同变化；C229 的 Wilcoxon 又检验的是两组相关系数整体位置差异。经验库应同时保留方法、统计问题和结论口径。

## 可复用经验与风险

可复用的部分：

- 先检查总和有效区间、检测点与文物编号关联，再建模。
- 百分比成分应使用闭合、零值替换和 log-ratio 思路，预测后恢复非负且总和为 100%。
- 属性关联、连续成分差异、监督分类、无监督亚类和成分关联是五个不同问题，应分别选模型。
- 未知样品应至少用两条方法链交叉检查，并报告敏感性和不确定度。

不应直接复用的部分：

- PbO 的 1.5%、6.155%、8.495% 阈值都只属于各自处理后的历史样本。
- 不应把未检测成分直接补 0 后做 clr；必须显式记录零值替换策略。
- C155 对非 2×2 稀疏列联表使用 Yates 校正、C229 把名义型颜色和纹饰编码后做 Spearman，均应改用精确或 Monte Carlo 列联表检验复核。
- 同一文物的多个检测点应按文物分组切分，避免训练集和测试集共享文物信息。
- “三亚类”没有外部标签，需用重采样稳定性、轮廓系数和领域解释共同验证。
- 相关或灰色关联不提供因果解释。
