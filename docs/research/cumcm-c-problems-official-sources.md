# 全国大学生数学建模竞赛 C 题官方资料清单

更新时间：2026-07-20

## 结论

- 全国大学生数学建模竞赛官网的“历年竞赛赛题”入口覆盖 1992—2025 年，可作为赛题和官方附件的主索引。
- 教育部中国大学生在线的“数学建模竞赛论文展示”入口覆盖 2012—2025 年，可查看组委会选择展示的论文。
- 近年的 C 题通常需要数据分析，并经常结合分类预测、评价或决策优化；但组委会没有规定 C 题每年必然是“数据分析题”。
- 官网赛题附件可在尊重页面条款的前提下作为首批原始资料来源。论文展示页多为逐页图片，并明确写有“未经全国大学生数学建模竞赛组委会书面许可，请勿转载”，因此项目当前只保存论文元数据和官方链接，不复制论文正文或图片。
- “在官网论文展示栏目出现”不能单独证明“全国一等奖”。奖项等级需要再与当年官方获奖名单按学校、队员或其他可识别信息交叉核验；未完成核验前统一标为“官方展示论文”。

## 已核实的论文展示与版权边界

以 [2024 C063 展示页](https://dxs.moe.gov.cn/zx/a/hd_sxjm_sxjmlw_2024qgdxssxjmjslwzs_2024ctlw/241104/1977958.shtml) 为例，论文被拆成 49 张逐页图片，页面底部明确禁止未经书面许可转载。因此后续采集分两层：

1. **可落库**：年份、题号、题名、展示编号、官方页面 URL、页数、访问时间、版权提示、奖项核验状态。
2. **暂不落库**：论文图片、论文全文 OCR、可再次分发的 PDF。

如果后续取得组委会书面许可，再把正文采集和结构化提炼打开；在此之前，可以让系统在用户主动打开官方页面或用户自行上传有权使用的论文时进行分析。

## 建议的第一批导入

先导入 2022—2025 四年的赛题和官方数据附件：

1. 2025：医疗时点选择与异常判定，覆盖分组、风险阈值和分类预测。
2. 2024：农业种植策略，覆盖约束优化、情景分析和稳健决策。
3. 2023：零售定价与补货，覆盖时间序列、需求估计和经营决策。
4. 2022：材料成分分析与鉴别，覆盖缺失处理、聚类/分类和敏感性分析。

这四年数据附件完整、主题差异大，最适合先验证 Issue #12 的“导入—解析—提炼—检索”闭环。论文部分先建官方链接目录；是否属于国家一等奖，必须在导入前通过当年官方获奖名单完成确认。

## 后续核验项

- 下载并解包 2022—2025 官方赛题压缩包，生成文件清单、哈希和许可证/来源元数据。
- 对 2012—2025 的 C 题展示论文逐篇登记页面 URL 和页数。
- 将展示论文与历年竞赛结果中的学校、队员等字段交叉匹配，只有匹配成功才标记“全国一等奖已确认”。
- 对没有论文展示的年份，仅保存赛题和官方数据；不从非官方网盘抓取来历不明的论文。
