# Curated competition experience library 1.0.0

This is the first curated built-in release. It contains one approved structured
case card for the 2022 CUMCM C problem, a source-backed keyword index, and the
project's mathematical-modeling skill catalog.

The original problem PDF, workbook, paper page images, and OCR text are not
redistributed. The case card contains paraphrased modeling experience, source
metadata, checksums, citations, review metadata, and explicit limitations only.

Historical results are references, not answers for a new task. Runtime use must
recheck assumptions, data grain, leakage risk, validation design, and sensitivity
before applying any historical method or threshold.
